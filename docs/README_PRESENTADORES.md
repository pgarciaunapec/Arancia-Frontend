## 💡 CONSEJOS PARA PRESENTADORES

1. **Conoce el flujo:** Practica antes, no improvises
2. **Ten contexto:** Cada módulo tiene preguntas comunes (busca "Q:")
3. **Sé específico:** Menciona URLs exactas ("Esto es en `/menu`")
4. **Muestra lo visual:** El frontend impacta primero
5. **Sin tecnicismos:** Di "orden" no "documento en colección"
6. **Prepara datos:** Ten órdenes, reservas, etc. de prueba
