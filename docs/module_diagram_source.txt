==========================================================
DEPENDENCY / DATA FLOW ARROWS
==========================================================

VERTICAL FLOW (top-to-bottom, main architecture):
main.tsx  -->  App.tsx  -->  React Router  -->  Pages

PAGES depend on:
Pages ---------> Layout Components (wrapped in header/footer/nav)
Pages ---------> UI Library (use buttons, cards, forms, etc.)
Pages ---------> State Management (read/write AuthContext, CartContext)
Pages ---------> Services Layer (fetch data via API calls)

STATE MANAGEMENT depends on:
AuthContext ----> authApi (login, register, token)
CartContext ----> cartApi (sync cart with server)

SERVICES LAYER connects to BACKEND:
Services Layer <====> Backend API  (HTTP REST, dashed bidirectional arrow)
                      Label: "HTTP/REST (JSON)"
                      Label: "Authorization: Bearer <JWT>"

BACKEND internal flow:
Routes --> Middleware (auth check) --> Controllers --> Models --> Database

SPECIFIC HIGHLIGHTED FLOWS (show as colored paths):
1. [Auth Flow - orange path]:
   Login page --> AuthContext --> authApi --> /api/auth/* --> User model --> MongoDB

2. [Order Flow - green path]:
   Menu --> CartContext --> Cart --> Checkout --> orderApi --> /api/orders --> Order model --> MongoDB

3. [Reservation Flow - blue path]:
   Reservations --> reservationApi --> /api/reservations --> Reservation model --> MongoDB
